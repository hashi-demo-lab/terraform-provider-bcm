### 5. Category Force Parameter (1 Test Fixed)

**File:** `internal/provider/resource_cmdevice_category.go`
**Lines Modified:** 753-866

**Problem:**
`force` parameter is client-side only (not returned by BCM API). Without preservation, Read() set it to null, causing idempotency test failures.

**Solution:**
Added state preservation logic mirroring existing `management_network` pattern:
```go
if !originalForce.IsNull() && !originalForce.IsUnknown() {
    state.Force = originalForce
} else {
    state.Force = types.BoolNull()
}
```
