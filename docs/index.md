# BCM Provider

~> **PROTOTYPE PROVIDER** - This is a prototype Terraform provider for Nvidia BCM (Base Command Manager). It is recommended to **fork this provider** for your own use and development. This provider is not officially supported and may have breaking changes.

The BCM provider allows Terraform to manage resources in Nvidia's Base Command Manager (BCM). It provides resources and data sources for managing cluster configurations including:

- Software Images
- Categories (node groups)
- Devices (compute nodes)
- Networks
- Users and Groups

## Requirements

- [Terraform](https://developer.hashicorp.com/terraform/downloads) >= 1.5
- A BCM endpoint with API access
- Valid BCM credentials

## Authentication

The provider can be configured using environment variables or provider block attributes:

```shell
export BCM_ENDPOINT="https://bcm.example.com:8081"
export BCM_USERNAME="automation-user"
export BCM_PASSWORD="your-secure-password"
```

### Optional

- `endpoint` (String) BCM JSON-RPC API endpoint (e.g., https://172.21.15.254:8081). Can also be set via BCM_ENDPOINT environment variable.
- `insecure_skip_verify` (Boolean) Skip TLS certificate verification. WARNING: This makes connections susceptible to man-in-the-middle attacks. Only use for testing with self-signed certificates.
- `password` (String, Sensitive) BCM password for authentication. Can also be set via BCM_PASSWORD environment variable.
- `timeout` (Number) API timeout in seconds (default: 30)
- `username` (String) BCM username for authentication. Can also be set via BCM_USERNAME environment variable.

## Example Usage

```terraform
terraform {
  required_version = ">= 1.5.0"

  required_providers {
    bcm = {
      source  = "hashi-demo-lab/bcm"
      version = "~> 0.1"
    }
  }
}

# Production-ready provider configuration using environment variables
# Set these in your environment:
#   export BCM_ENDPOINT="https://bcm.example.com:8081"
#   export BCM_USERNAME="automation-user"
#   export BCM_PASSWORD="your-secure-password"
provider "bcm" {
  # Use environment variables for sensitive values (best practice)
  endpoint             = var.bcm_endpoint
  username             = var.bcm_username
  password             = var.bcm_password
  insecure_skip_verify = var.insecure_skip_verify
  timeout              = var.bcm_timeout
}

# Variables for provider configuration
variable "bcm_endpoint" {

variable "insecure_skip_verify" {
```
