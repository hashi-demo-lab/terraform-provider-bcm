# bcm_cmnet_network (Resource)

Manages a BCM network configuration with full CRUD lifecycle support.

## Example Usage

```terraform
resource "bcm_cmnet_network" "example" {
  name             = "compute-network"
  subnet           = "10.0.1.0/24"
  gateway          = "10.0.1.1"
  mtu              = 9000
  domain_name      = "cluster.local"
  dhcp_range_start = "10.0.1.100"
  dhcp_range_end   = "10.0.1.200"
  notes            = "High-performance compute network managed by Terraform"
}
```

## Schema

### Required

- `name` (String) Unique network name within the BCM cluster.

### Optional

- `dhcp_range_end` (String) DHCP pool end IP address. Setting both dhcp_range_start and dhcp_range_end enables DHCP.
- `dhcp_range_start` (String) DHCP pool start IP address. Setting both dhcp_range_start and dhcp_range_end enables DHCP.
- `domain_name` (String) DNS domain name for the network. Default: 'cluster.local' if not specified.
- `gateway` (String) Gateway IP address for the network.
- `mtu` (Number) Maximum transmission unit (MTU) for the network. Default: 1500.
- `notes` (String) User notes or description for the network.
- `subnet` (String) Network subnet in CIDR notation (e.g., '10.0.1.0/24'). When set, base_address and netmask_bits are automatically computed.

### Read-Only

- `base_address` (String) Network base IP address (parsed from subnet or assigned by BCM).
- `base_type` (String) BCM entity base type (always 'Network').
- `bootable` (Boolean) BCM-assigned bootable network flag.
- `child_type` (String) BCM entity child type.
- `dhcp_enabled` (Boolean) Whether DHCP is enabled (derived from dhcp_range_start and dhcp_range_end).
- `id` (String) Network unique identifier (same as uuid).
- `management` (Boolean) BCM-assigned management network flag.
- `modified` (Boolean) BCM modification flag.
- `netmask_bits` (Number) Network mask bits (parsed from subnet or assigned by BCM).
- `network_type` (String) BCM-assigned network type (e.g., INTERNAL, GLOBAL).
- `revision` (String) BCM revision identifier for concurrency control.
- `to_be_removed` (Boolean) BCM removal flag.
- `uuid` (String) BCM-assigned UUID for the network.
