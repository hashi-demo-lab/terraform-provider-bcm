# bcm_cmuser_user (Resource)

Manages a BCM Unix user account.

This resource enables full lifecycle management of BCM users including creation, updating attributes, importing existing users, and deletion. Users are required for DGX BasePOD automation workflows before Kubernetes cluster user setup.

**Note**: The `password` attribute is write-only and will never be returned by the BCM API. The password is preserved in Terraform state but marked as sensitive.

## Example Usage

```terraform
# Basic user creation with minimal required attributes
resource "bcm_cmuser_user" "basic" {
  username = "testuser01"
  password = var.user_password
}

# Full user configuration with all attributes
resource "bcm_cmuser_user" "developer" {
  username       = "developer01"
  password       = var.developer_password
  full_name      = "Developer One"
  surname        = "One"
  email          = "developer01@example.com"
  home_directory = "/home/developer01"
  shell          = "/bin/zsh"
  notes          = "DGX BasePOD developer account"

  authorized_ssh_keys = <<-EOT
    ssh-rsa AAAAB3NzaC1yc2EAAAA... developer01@workstation
    ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... developer01@laptop
  EOT

  # Shadow password settings
  shadow_max     = 90 # Password expires after 90 days
  shadow_warning = 14 # Warn 14 days before expiration
}

# Service account with specific UID/GID
resource "bcm_cmuser_user" "service_account" {
  username       = "svc_backup"
  password       = var.service_password
  uid            = 2001
  gid            = 2001
  full_name      = "Backup Service Account"
  home_directory = "/var/lib/backup"
  shell          = "/sbin/nologin"
  notes          = "Service account for automated backups"
}

# Variables (define in terraform.tfvars or via environment)
variable "user_password" {
  description = "Password for the test user"
  type        = string
  sensitive   = true
  default     = "TestUser123!"
}

variable "developer_password" {
  description = "Password for the developer user"
  type        = string
  sensitive   = true
  default     = "DevUser123!"
}

variable "service_password" {
  description = "Password for the service account"
  type        = string
  sensitive   = true
  default     = "SvcAccount123!"
}
```

## Schema

### Required

- `password` (String, Sensitive) User password (write-only, never returned by BCM API). Required for user creation.
- `username` (String) User login name (1-32 characters, must start with letter, alphanumeric and underscore only)

### Optional

- `authorized_ssh_keys` (String) SSH authorized public keys (may be multi-line for multiple keys). **Known Limitation**: BCM API does not return this field on read - values are stored in Terraform state only.
- `email` (String) User's email address
- `force` (Boolean) Force operation even with validation warnings. Defaults to `false`.
- `full_name` (String) User's full display name (maps to commonName in BCM). Defaults to username if not specified.
- `gid` (Number) Primary group ID (GID). If not specified, BCM auto-assigns (typically creates a group with same name as user).
- `home_directory` (String) User home directory path. Defaults to `/home/{username}`.
- `notes` (String) Administrative notes about the user
- `shadow_inactive` (Number) Account inactive grace period in days after password expiration. Defaults to `0`.
- `shadow_max` (Number) Maximum password age in days. Defaults to `99999` (effectively no expiration).
- `shadow_min` (Number) Minimum password age in days (time before password can be changed). Defaults to `0`.
- `shadow_warning` (Number) Password expiration warning period in days. Defaults to `7`.
- `shell` (String) Login shell path. Defaults to `/bin/bash`.
- `surname` (String) User's surname (last name). Defaults to username if not specified.
- `uid` (Number) Unix user ID (UID). If not specified, BCM auto-assigns the next available UID.

### Read-Only

- `account_active` (Boolean) Whether the account is active (not expired). Computed from shadow_expire field.
- `id` (String) Resource identifier (same as UUID)
- `shadow_expire` (Number) Account expiration date in days since Unix epoch (1970-01-01). Value of -1 means account never expires.
- `shadow_last_change` (Number) Last password change date in days since Unix epoch
- `uuid` (String) Unique identifier assigned by BCM
