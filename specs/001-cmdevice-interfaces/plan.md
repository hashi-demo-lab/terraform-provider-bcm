# Implementation Plan: BCM CMDevice Interfaces Data Source

**Branch**: `001-cmdevice-interfaces` | **Date**: 2025-11-23 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/workspace/specs/001-cmdevice-interfaces/spec.md`

## Summary

Implement a Terraform data source (`data.bcm_cmdevice_interfaces`) that retrieves and filters network interface information from BCM compute nodes. The data source will flatten nested interface arrays from the cmdevice.getNodes API response and support client-side filtering by device_id, interface type, and network_id. This enables administrators to discover cluster network topology and plan network configurations.

**Technical Approach**: Use list-and-filter pattern with cmdevice.getNodes API (no dedicated interface endpoint exists), extract interfaces from nested arrays, attach parent node UUID as device_id, and apply client-side filters with AND logic.

**Research Tasks**:

1. **API Response Exploration**: Call cmdevice.getNodes and examine the structure of nested "interfaces" arrays

   - Verify NetworkPhysicalInterface, NetworkBondInterface, NetworkBMCInterface exist

   - Identify bond mode field name and possible values

   - Interfaces without IP addresses (ip field null/missing)
   - Interfaces without IPv6 addresses (ipv6Ip field null/missing)
   - Verify existing helper functions handle all cases correctly

5. **Performance Baseline**: Test query performance with realistic cluster sizes
   - Measure time to retrieve 10 nodes with 5 interfaces each
   - Measure time to retrieve 100 nodes with 10 interfaces each
   - Verify < 30 second requirement is achievable

### Data Model Design

**Output**: `data-model.md`

**Key Entities**:

1. **CMDeviceInterfacesDataSource** (Terraform data source)
   - ID: types.String (placeholder, always "placeholder")
   - Filter: InterfaceFilterModel (optional, nested object)
   - Interfaces: []InterfaceModel (computed, list of interface objects)

2. **InterfaceFilterModel** (filter criteria)
   - DeviceID: types.String (optional, filter by parent node UUID)
   - Type: types.String (optional, filter by interface type: physical/bond/bmc)
   - NetworkID: types.String (optional, filter by assigned network UUID)

3. **InterfaceModel** (network interface entity)
   - UUID: types.String (computed, interface unique identifier)
   - Name: types.String (computed, interface name like "eth0")
   - Type: types.String (computed, simplified type: physical/bond/bmc)
   - ChildType: types.String (computed, BCM API childType value)
   - BaseType: types.String (computed, always "NetworkInterface")
   - DeviceID: types.String (computed, parent node UUID - derived during flattening)
   - NetworkID: types.String (computed, assigned network UUID from "network" field)
   - MACAddress: types.String (computed, MAC address from "mac" field)
   - IPAddress: types.String (computed, IPv4 from "ip" field, nullable)
   - IPv6Address: types.String (computed, IPv6 from "ipv6Ip" field, nullable)
   - DHCPEnabled: types.Bool (computed, from "dhcp" field)
   - CardType: types.String (computed, from "cardtype" field, e.g., "Ethernet")
   - Bootable: types.Bool (computed, PXE boot capability)
   - StartIf: types.String (computed, startup condition: ALWAYS/NEVER/HOTPLUG)

**Relationships**:
- InterfaceModel.DeviceID → references parent node's UUID (many-to-one)
- InterfaceModel.NetworkID → references network UUID (many-to-one, nullable)

**Field Mappings** (Terraform schema → BCM API):

| Terraform Schema | BCM API Field | Type | Nullable | Notes |
|-----------------|---------------|------|----------|-------|
| uuid | uuid | string | No | Unique identifier |
| name | name | string | No | Interface name |
| child_type | childType | string | No | Raw type value |
| type | childType | string | No | Computed from childType |
| base_type | baseType | string | No | Always "NetworkInterface" |
| device_id | (derived) | string | No | Parent node's uuid |
| network_id | network | string | Yes | Network assignment |
| mac_address | mac | string | No | MAC address |
| ip_address | ip | string | Yes | IPv4 address |
| ipv6_address | ipv6Ip | string | Yes | IPv6 address |
| dhcp_enabled | dhcp | bool | No | DHCP configuration |

### API Contracts

**Output**: `contracts/interface-schema.md`

**BCM API Interaction Contract**:

```json
{
  "service": "cmdevice",
  "call": "getNodes",
  "args": []
}
```

**Expected Response Structure** (per node):

```json
{
  "uuid": "node-uuid-123",
  "hostname": "compute-01",
  "interfaces": [
    {
      "uuid": "interface-uuid-456",
      "name": "eth0",
      "childType": "NetworkPhysicalInterface",
      "baseType": "NetworkInterface",
      "mac": "00:11:22:33:44:55",
      "ip": "192.168.1.100",
      "ipv6Ip": "fe80::211:22ff:fe33:4455",
      "network": "network-uuid-789",
      "dhcp": true,
      "cardtype": "Ethernet",
      "bootable": true,
      "startIf": "ALWAYS"
    }
  ]
}
```

**Data Transformation Pipeline**:

1. Call cmdevice.getNodes → get array of node objects
2. For each node:
   - Extract node UUID as device_id
   - Extract "interfaces" array
   - For each interface in array:
     - Map all BCM API fields to Terraform schema fields
     - Derive "type" from "childType" (normalize to lowercase)
     - Attach device_id from parent node
     - Handle nullable fields with helper functions
3. Flatten all interface arrays into single list
4. Apply client-side filters (AND logic):
   - Filter by device_id if specified
   - Filter by type if specified
   - Filter by network_id if specified
5. Set data source state with filtered interface list

**Filter Matching Logic**:

```go
// matchesInterfaceFilter implements AND logic across all filters
func matchesInterfaceFilter(iface InterfaceModel, filter *InterfaceFilterModel) bool {
    if filter == nil {
        return true // No filter = match all
    }

    // Device ID filter (exact match)
    if !filter.DeviceID.IsNull() && iface.DeviceID.ValueString() != filter.DeviceID.ValueString() {
        return false
    }

    // Type filter (exact match on normalized type)
    if !filter.Type.IsNull() && iface.Type.ValueString() != filter.Type.ValueString() {
        return false
    }

    // Network ID filter (exact match, exclude null network_id interfaces)
    if !filter.NetworkID.IsNull() {
        if iface.NetworkID.IsNull() || iface.NetworkID.ValueString() != filter.NetworkID.ValueString() {
            return false
        }
    }

    return true // Matches all filters
}
```
