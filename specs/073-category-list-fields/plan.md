## Summary

This investigation plan documents and verifies the BCM API behavior for category list fields that appear to not persist: `static_routes`, `fsexports`, `roles`, `gpu_settings`, and `services`. The plan includes direct API verification, alternative API discovery, documentation updates, and code validation to ensure the provider correctly handles these BCM limitations.

### Known Limitations

~> **BCM API Limitation**: The following list fields are accepted by BCM but are **not persisted** after category creation:
- `static_routes` - Static network routes
- `fsexports` - NFS filesystem exports
- `roles` - Service role assignments
- `gpu_settings` - GPU hardware configuration
- `services` - Service configurations

These values are stored in Terraform state to prevent drift detection errors, but they will not be present if you import an existing category. After import, you must re-apply your configuration to restore these values in state.

For each affected field, add inline warnings:

```markdown

  **Note**: BCM API does not persist this field - values are preserved in Terraform state only.
```

# BCM Category List Fields - Developer Quick Start

## Background
BCM API accepts certain list fields on category create/update but returns empty arrays on read.

## Affected Fields
| Field | Terraform Attribute | BCM API Field |
|-------|---------------------|---------------|
| Static Routes | `static_routes` | `staticRoutes` |
| FS Exports | `fsexports` | `fsexports` |
| Roles | `roles` | `roles` |
| GPU Settings | `gpu_settings` | `gpuSettings` |
| Services | `services` | `services` |

## Provider Behavior
1. **Create/Update**: Values sent to BCM API (accepted but not stored)
2. **Read**: BCM returns empty arrays; provider preserves plan/state values
3. **Import**: Fields will be empty - user must re-apply config
4. **Drift**: No false positives due to preservation logic

## Testing These Fields
- Idempotency tests must pass (no plan changes after apply)
- Import tests use `ImportStateVerifyIgnore` for affected fields
- Drift tests not applicable (BCM doesn't persist to detect drift)
