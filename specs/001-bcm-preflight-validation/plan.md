# Implementation Plan: BCM Pre-flight Validation

**Branch**: `001-bcm-preflight-validation` | **Date**: 2025-11-24 | **Spec**: [spec.md](/workspace/specs/001-bcm-preflight-validation/spec.md)

**Input**: Implement pre-flight validation using BCM validate* API methods across all 5 resource types (software images, categories, devices, networks, kubernetes clusters). The BCM API provides validate* methods that perform server-side validation before CRUD operations.

## Summary

This feature adds pre-flight validation to the Terraform Provider for BCM by calling BCM's server-side validate* methods before CREATE and UPDATE operations. A generic ValidateEntity() helper function will be added to bcm_client.go to validate entities across all 5 resource types (software images, categories, devices, networks, kubernetes clusters). The validation will catch invalid field values, duplicate names, and other issues before API calls, providing immediate user feedback with field-specific error messages. ERROR severity validation failures will halt operations, while WARNING severity issues will display advisory messages but allow operations to proceed.

### 1.3 Component Design

#### ValidateEntity() Helper Function

**Location**: `internal/provider/bcm_client.go`

**Signature**:
```go
func (c *BCMClient) ValidateEntity(ctx context.Context, service, validateMethod string, entity map[string]interface{}, isCreate bool) ([]ValidationError, error)
```

**Parameters**:
- `ctx context.Context`: Request context for logging and cancellation
- `service string`: BCM service name (CMPart, CMDevice, CMNet, cmkube)
- `validateMethod string`: Validation method name (e.g., "validateSoftwareImage")
- `entity map[string]interface{}`: Entity to validate (same structure as create/update)
- `isCreate bool`: Whether this is CREATE operation (true) or UPDATE operation (false)

**Returns**:
- `[]ValidationError`: Array of validation errors/warnings (empty if validation passes)
- `error`: API communication error (not validation error)

**Logic**:
1. Call BCM API: `CallJSONRPC(ctx, service, validateMethod, entity)`
2. Parse response as array of validation objects
3. If isCreate==true: Filter out errors where Field=="uuid" AND Message contains "Zero UUID"
4. Convert remaining validation objects to ValidationError structs
5. Return validation errors (empty array if all pass)

**Error Handling**:
- API communication failures return non-nil error
- Malformed JSON responses return parsing error
- Validation failures return populated ValidationError array with nil error

#### ValidationError Struct

**Location**: `internal/provider/bcm_client.go`

**Definition**:
```go
// ValidationError represents a single validation issue from BCM API
type ValidationError struct {
    Field      string // Attribute that failed validation
    Message    string // Human-readable error description
    ErrorCode  string // BCM error code (BAD_VALUE, DUPLICATE_FIELD, etc.)
    Severity   string // ERROR or WARNING
    EntityUUID string // Related entity UUID (may be empty)
}

// IsError returns true if validation error should halt operation
func (v ValidationError) IsError() bool {
    return v.Severity == "ERROR" || v.Severity == "" // Unknown severity treated as ERROR
}

// IsWarning returns true if validation error is advisory only
func (v ValidationError) IsWarning() bool {
    return v.Severity == "WARNING"
}
```

```go
func (r *CMPartSoftwareImageResource) Create(ctx context.Context, req resource.CreateRequest, resp *resource.CreateResponse) {
    var data CMPartSoftwareImageResourceModel
    resp.Diagnostics.Append(req.Plan.Get(ctx, &data)...)
    if resp.Diagnostics.HasError() {
        return
    }

    // Build API entity
    entity := buildSoftwareImageAPIEntity(ctx, data)

    // PRE-FLIGHT VALIDATION (NEW)
    validationErrors, err := r.client.ValidateEntity(ctx, "CMPart", "validateSoftwareImage", entity, true)
    if err != nil {
        resp.Diagnostics.AddError(
            "Validation API Error",
            fmt.Sprintf("Could not validate software image: %s", err.Error()),
        )
        return
    }

    // Process validation results
    hasErrors := false
    for _, valErr := range validationErrors {
        if valErr.IsError() {
            resp.Diagnostics.AddError(
                fmt.Sprintf("Validation Error: %s", valErr.Field),
                valErr.Message,
            )
            hasErrors = true
        } else if valErr.IsWarning() {
            resp.Diagnostics.AddWarning(
                fmt.Sprintf("Validation Warning: %s", valErr.Field),
                valErr.Message,
            )
        }
    }

    // Halt if validation errors found
    if hasErrors {
        return
    }

    // Continue with CREATE operation...
    body, err := r.client.CallJSONRPC(ctx, "CMPart", "addSoftwareImage", entity, false)
    // ... rest of create logic
}
```
